# Лёгкий дом

Минималистичный лаунчер для Android TV / Google TV (проверялся под Sony Bravia 3, Android 12).
Без рекламы, без доступа в интернет, без фоновой работы — кроме одной службы
специальных возможностей, которая возвращает на «Лёгкий дом» по кнопке Home.

## Скачать

Ссылка на последнюю сборку (всегда одна и та же):

https://github.com/tvinpick/androidx.tv/releases/latest/download/lighthome.apk

## Установка через Downloader

1. На телевизоре установите приложение **Downloader** (AFTVnews) из Google Play.
2. Разрешите ему установку приложений: Настройки → Приложения → Безопасность и ограничения →
   Неизвестные источники → Downloader → включить.
3. Откройте Downloader, в поле адреса введите ссылку выше и нажмите **Go**.
4. После загрузки нажмите **Установить**. Обновления ставятся поверх тем же способом
   (сборки подписаны одним ключом).
5. Запустите «Лёгкий дом» и следуйте подсказке: Настройки → Система → Спец. возможности →
   «Лёгкий дом» → включить. После этого кнопка Home открывает «Лёгкий дом».

Перехват кнопки Home можно выключить в «Настройках оболочки».

## Управление пультом

- Долгое нажатие OK на плитке — переместить стрелками, сдвинуть, перенести в другой раздел,
  сведения о приложении, удалить.
- Долгое нажатие на названии раздела — переименовать, размер плиток, порядок, удалить.
- «+» в конце ряда — выбор приложений для раздела (сортировка по имени или по дате установки,
  быстрый переход по буквам).

## Фон

«Настройки оболочки» → «Фон: последние файлы». Показываются картинки и видео из памяти ТВ
и с флешки, новые сверху (удобно для файлов, присланных через Send Files to TV).
Можно поставить картинку, видео (без звука, по кругу) или слайд-шоу из папки.

## Резервная копия

«Экспорт настроек» сохраняет файл `lighthome-settings-….png` в `Pictures/LightHome`
в памяти ТВ и на флешке. «Импорт настроек» загружает его обратно — в том числе на другом ТВ.

## Сборка

```
./gradlew assembleRelease
```

При каждом push в `main` GitHub Actions собирает APK и перевыкладывает релиз `latest`
с файлом `lighthome.apk`.
